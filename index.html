Three Modes

三大核心模式，一条运行时

Code 面向真实代码库与交付，Design 面向 UI 方案与原型，Write 面向长文档与发布内容。三者共用同一个 Dagong 运行时、Provider 配置、审批机制与会话能力。

Code

把本地目录交给它处理代码、需求、计划与变更审查。读取项目上下文、执行命令、修改文件，提交前逐次审查变更。

真实代码库 · 变更审查

Design

从自然语言、需求草稿或现有界面生成设计稿、交互式 HTML 原型与共享设计系统，并一键交给 Code 实现。

UI 原型 · Design→Code

Write

独立 Markdown 工作区，支持文件树、Live/Source/Split/Preview、选区 inline agent，以及 HTML / PDF / DOC / DOCX 导出。

长文写作 · 多格式导出
Requirement-First

需求 → 设计 → 计划 → 编码 → 验收

Dagong 想探索的是下一代 Agent 工作流，而不是把一个聊天框简单贴到 IDE 上。让 AI Agent 从“即时问答”走向“需求驱动的软件生产流程”。

Model Stack

核心模型组合：完整能力 + 极致性价比

需求先行的流程比普通聊天更长、更依赖反复调用模型。Dagong 以 DeepSeek、Xiaomi MiMo、MiniMax 为核心组合，用高性价比模型承担完整桌面 Agent 工作流。

DeepSeek

默认文本与推理主模型，提供 deepseek-v4-pro / deepseek-v4-flash，支撑代码、计划、审查、长上下文会话与自动模型路由。

Xiaomi MiMo

高性价比多模态与语音入口，覆盖长上下文文本、视觉输入、ASR 语音转写、TTS 语音生成与 Token Plan。

MiniMax

补齐完整媒体生成能力，覆盖文本模型、图片生成、语音生成、音乐生成、视频生成与 Token Plan。

Capabilities

核心能力

从需求澄清到可执行计划，从工具审批到多模态生成，Dagong 把 AI 真正放进日常工作。

需求优先 Agent

草稿澄清、结构化、生成设计稿与原型，再进入计划、Todo、编码与验收。

Code 工作台

围绕真实代码库对话，读上下文、跑命令、改文件、提交前审查变更。

Design 模式

自然语言生成设计稿、交互 HTML 原型、流程图，共享设计系统，一键交 Code。

计划与审查

需求、/plan、Todo、/goal、旁支对话、会话压缩、分叉、归档与 /review。

可控的改动

工具审批、文件系统权限模式、内联 diff、变更审查面板与 /review。

Write 写作

Markdown 文件树、预览切换、补全、选区改写、图片附件与多格式导出。

自动化与远程入口

飞书 / Lark / 微信连接、本地 webhook / relay、一次性或周期性定时任务。

可视化 Loop 工作流

节点式编排画布，多步 Agent 流程可画、可跑、可复用，绑定 hook 阶段。

多模态与媒体

图片附件、视觉输入、语音转写、图片/语音/音乐/视频生成随 Provider 启用。

Get Started

快速开始

下载发布版，或从源码运行。

路径 A · 下载发布版

前往 GitHub Releases 获取 macOS（.dmg / .zip，Intel / Apple Silicon）、Windows（NSIS）与 Linux（AppImage）。

前往 Releases v0.3.0

首次启动：选择语言 → 选择模型服务并填写 API Key → 进入 Code / Design / Write。

路径 B · 从源码运行

环境要求：Node.js 20+，以及至少一个模型服务凭据（DeepSeek / MiMo / MiniMax / 自定义）。

# 克隆并安装
git clone https://github.com/polimao/Dagong.git
cd Dagong
npm install
npm run dev

中国大陆可加镜像：npm install --registry=https://registry.npmmirror.com
